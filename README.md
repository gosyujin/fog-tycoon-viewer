# fog-tycoon-viewer

fog-tycoon の外出先用ビューア(静的ページ)。GitHub Pages に置く。**コード・鍵・データは含まない。**

開くと App key の入力画面が出て、Dropbox で認可した端末だけが `points.json` を読める(認可の範囲は App Folder 内の読み書き。書くのはチェックインだけ)。
データは本体 `fog-tycoon` の `scripts/export.mjs` が Dropbox の App Folder(`/points.json`)に書く。

## セットアップ

1. Dropbox App Console で App Folder 型のアプリを作り、Permissions で `files.content.read` と `files.content.write` を有効にする。
2. Redirect URIs に Pages の URL(`https://note.gosyujin.com/fog-tycoon-viewer/`)を登録する。
3. この repo を GitHub に push し、Settings → Pages で `main` / root を公開する。
4. スマホで Pages を開き、App key を入力して認可する。

## 機能
- 霧(通った場所だけ晴れる) / ヒートマップ(右下の 🌫/🔥 ボタンで切替。通った場所を訪問日数で 青=1日・緑=2〜3日・黄=4〜9日・赤=10日〜 に色分けし、凡例を表示。選択はこの端末に記憶) / 軌跡(既定オフ) / 霧の濃さ / 晴れ半径 / 期間の切り替え(⚙ にまとめ、値はこの端末に記憶する)
- この辺りの履歴(右上の ⚙ の下の 🕘 を押してから地図をタップ。その周り(半径 50/100/200/500m)に来た日を新しい順に一覧にし、日ごとのいた時間帯を出す。日の行を押すと、その日の軌跡を橙で重ねる。リアルタイム追跡で取った今日の点も含む。全期間の点から探し、期間フィルタには影響されない)
- チェックイン(下中央の ✅。シートは画面の下端に出て、ソフトキーボードが出たらその上に上がる(`visualViewport`)。入力中(キーボードが出ている間)は、時刻・滞在候補・位置のボタンを隠してシートを小さくし(場所とメモは横並び)、選んだ位置が見える地図の面積を確保する(iPhone ではキーボードで見える高さが 400px 台まで縮み、フルのシートだと位置を置く余地が無くなる)。開いてもキーボードは自動では出さない(上から 位置 → 時刻 → 滞在から選ぶ → 近くの場所 → 場所の入力 の順。過去の場所名の候補は、場所の欄に打ち始めてから出す)。入力欄の名前・説明文に「名前」を使わない(iOS が人の名前の欄と判断して「連絡先を自動入力」を出すため)。位置は「現在地」か「地図で指定」(押してから地図をタップ)、名前・時刻(既定は今。過去に変えられる)・メモ(任意)を入れて保存)。近く100m以内の登録済みの場所が候補に出て、同じ名前で300m以内なら同じ場所に付く(新しい名前なら場所を新規登録)。Dropbox の `/checkins.json` に書き、書く前に最新を読み直して `rev` つきで更新するので、他の端末の書き込みと競合したら読み直してやり直す。圏外のときは端末のキュー(localStorage)に溜め、通信できたとき・アプリに戻ったときに送る。ピンを押すと来た日の一覧が出る(ポップアップは最前面)。削除は、一覧の「編集」を押してから出る「削除」で(確認ダイアログつき。うっかり押さないよう、既定では出さない)
- 入れ忘れのチェックイン(✅ のシートの「この日の滞在から選ぶ」。時刻欄の日に、同じ所(半径 `STAY_R`=60m)に10分以上(`STAY_MIN_SEC`)いた場所を点から探して時刻順に出す。タップすると位置・時刻(滞在の最初の点)・近くの登録済みの場所の名前が入り、地図はその位置がシートより上の見える範囲の真ん中に来るよう動く(キーボードで iOS がページをスクロールした分も考慮)ので、名前を確かめて保存。すでにチェックイン済みの滞在は薄く出す。候補は保存しない。「地図で指定」のときも、その日の点が100m以内にあれば時刻を合わせる)
- ピン(右下の 🌫/🔥 の左の 📍 でオンオフ。名前は寄ったとき(ズーム15以上)だけ出る。選択はこの端末に記憶)。「この辺りの履歴」にもチェックインを出す(点が無い日も)
- 現在地ボタン(下中央の ✅ の左の ◎。起動時は現在地を表示(測位に失敗したら低精度で1回取り直す)。10分以内の再読み込み・復帰は最後の表示位置を維持。HTTPS が要るので Pages 上でだけ使える)
- コンパス(◎を長押し。地図が端末の向きに回り、向いている方向が上になる。もう一度長押しで北上に戻る。回転は leaflet-rotate。iOS は「モーションと方向」の許可が要る)
- リアルタイム追跡(✅の右の ●。押すと連続測位して軌跡(橙)と霧の晴れ範囲に即反映、画面は点けたまま。追従中は現在地が画面の中心に居続け、縮尺は変えない(追跡開始時だけ街区が見える縮尺まで寄る。追従中のズームは画面中心基準)。地図を1本指で動かすと追従が外れ、◎で戻る(2本指のピンチでは外れない)。追跡した点は保存しない。バックグラウンドや圏外を挟んで移動した区間は、軌跡を直線で結ばず切る)
- 地図の1本指ズーム(ダブルタップして指を離さず上下にドラッグ。向きは `app.js` の `ONE_FINGER_DIR` で反転できる)
- ボタン類はダブルタップでページが拡大しない(`touch-action: manipulation`。拡大縮小は地図だけ)
- 画面左下に `build <sha> (<時刻>)` を表示。起動時に最新のデプロイと比べ、古ければ読み直す(GitHub Actions が `build-info.js` を上書き。ローカルは `dev`)
- 地図タイルを端末にキャッシュ(`sw.js`。見たタイルだけを最大3000枚・14日間保存し、2回目以降は通信せずに表示。オフラインでも見たことのある場所は出る)。初期表示は前回の位置から始め、東京や日本全体を経由しない
- 🔄 (左下) は差分の同期: Tailscale につながった Mac の同期サーバ(fog-tycoon の `scripts/sync-server.mjs`)の `/sync/recent` に依頼し、Mac が直近の分だけ Dawarich から取り直して `recent.json` に書いたら、それを取り込む(1秒前後)。⚙ の「Dawarich と全件で同期」は `/sync`(全件の書き出し、約15秒)のあと `points.json` を読み直す。Dawarich 側で古い点を消したあとすぐ反映したいとき用(1時間ごとの全件でも正される)。同期先の URL(Mac の `tailscale serve` の `https://…ts.net`)は ⚙ に入力し、この端末にだけ保存する。同期サーバが古く `/sync/recent` が無いとき(404)は、その旨を出す
- 直近の点の自動取り込み(表示中は60秒ごとに Dropbox の `/recent.json` を読み、`points.json` の `since` 以降をその点で置き換えて霧・統計に反映する。GPS は使わない。Mac が60秒ごとに Dawarich から直近の分だけ書く(fog-tycoon の README の「差分エクスポート」)。最後に全件を読み込んだ以降に Dawarich に届いた点は、橙の線でも描く。画面が裏に回ったら止め、戻ったらすぐ読む。`recent.json` の `since` が読み込み済みの `points.json` より新しいとき(全件が書き直された)は全件を読み直す。全件より古い `recent.json` は使わない。霧に関係しないヒートマップのセルと軌跡は、切り替えたときに作り直す。リアルタイム追跡の点は、Dawarich から届いた最後の点より新しい分だけヒートマップに足す)
- 通信できないときは端末に残した控えを表示

## 注意
- 履歴・ピンの層 (`recall` / `pins`) は、回る層 (leaflet-rotate の `rotatePane`) の中に作る。`mapPane` の直下に作ると、回らない層 (ポップアップ・ラベル) の上に重なってしまう。
- 霧の描画コード (`Fog`) は本体 `fog-tycoon` の `app.js` と同じ(本体は地図が回らないが、回転対応のコードも同じものを入れてある)。直すときは両方に反映する。
- `points.json` は行動履歴。Pages の URL は公開されるが、データは Dropbox 認可がないと読めない。
